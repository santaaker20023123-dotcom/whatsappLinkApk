# whatsappLinkApk

## To-do list

A browser-based to-do list is available at `/todo` when the app is running. It supports adding, completing, deleting, and filtering tasks, and stores them in the browser's local storage.

Start the server with:

```sh
npm install
npm start
```

Then open `http://localhost:3000/todo`. Tasks are saved per browser and device; they are not synced to a server.
